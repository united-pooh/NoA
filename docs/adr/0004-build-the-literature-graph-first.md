# Make the literature graph NoA's first product slice

NoA's first MCP release will collect scholarly literature, preserve source-attributed metadata and evidence, connect related research, and produce traceable technical-lineage views. Experiment logs and other research assets may later join the same research graph, but they are not part of the first implementation slice.

## Consequences

The first release is not a general autonomous experiment runner. Its bounded runs are collection, import, enrichment, semantic-review, search, and lineage-generation workflows. The existing research-log Skill will be replaced rather than retained as a parallel product surface.
